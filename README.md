# Saritha Chowdary — Portfolio

Personal portfolio showcasing my work as an AI Software Engineer — LLM-driven agents, AI/ML projects, full-stack applications, automation workflows, technical skills, achievements, and experience.

🔗 **Live site:** https://chowdarysaritha311.github.io/saritha-dev-portfolio/

## What's in this repo

| File / Folder | Purpose |
|---|---|
| `index.html` | The portfolio site itself (single-file, no build step needed) |
| `resume.pdf` | Downloadable resume (linked from the nav, hero, and contact section) |
| `images/` | Profile photo and all company logos used across the site |

## Running it locally

No build tools required — just open `index.html` directly in a browser, or serve the folder with any static server:

```
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Deployment

This repo is deployed via **GitHub Pages** (Settings → Pages → Deploy from branch → `main` → `/root`). Any commit to `main` goes live within a minute or two at the link above.
