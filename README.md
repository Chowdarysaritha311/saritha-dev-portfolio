## 📖 About

A single-page portfolio built from scratch — no frameworks, no build step, just HTML/CSS/JS — showcasing my work as an **AI Software Engineer at Hello Recruiter®**, where I evaluate and build the LLM-driven agents that run live candidate interviews.

The site covers:

- 🧠 **What I Build** — the pillars of my work: Agentic AI, Full-Stack Development, Automation
- 🧾 **Project case studies** — Problem → Approach → Outcome, not just a screenshot and a tagline
- 💻 **An interactive terminal** — type real commands (`about`, `experience`, `skills`, `resume`, and more) to explore my background
- 💼 **Full experience timeline** — with company logos, from my first internship to my current role
- 🏆 **Awards & certifications**

## 🚀 Running It Locally

No installation needed:

```bash
git clone https://github.com/Chowdarysaritha311/saritha-dev-portfolio.git
cd saritha-dev-portfolio
python3 -m http.server
```

Then open `http://localhost:8000` in your browser. Or just double-click `index.html` directly.
